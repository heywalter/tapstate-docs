Choose the system you want tapstate to read from or write to. Select a connector
to open its prerequisites, connection fields, documented roles and modes, and
limitations. Use a [server-side connection test](/docs/guides/register-connectors#test-a-connection)
before using a production endpoint.

## Maturity labels

- **GA** means the connector guide and configuration contract are mature.
- **Preview** means the guide or configuration contract can still change.

Maturity does not mean that a connector JAR is bundled with every tapstate
release or that every listed role and mode has passed an end-to-end release
test.

## Release-tested marker

The **E2E** marker identifies a connector that participates in a published
end-to-end release flow. It currently marks MySQL and MongoDB, which are the
source and target in the published Quickstart. A missing marker does not mean
that a connector is unsupported; it means that connector is not part of that
published flow.

## How to read roles and modes

Hover a label or its information icon to see its exact meaning.

- **Source** reads from the listed system in the shown mode.
- **Target** writes data to the listed system.
- **Snapshot** reads the selected data once. **CDC** starts with existing data,
  then captures later committed changes.
- A dash means the current catalog does not report that role or read mode.

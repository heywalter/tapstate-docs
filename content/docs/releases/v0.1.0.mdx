Released July 28, 2026 · Preview

`v0.1.0` is the first tapstate preview. It is for local evaluation, not
production use. See the [GitHub release](https://github.com/tapstate/tapstate/releases/tag/v0.1.0)
for downloadable CLI archives and checksums.

## Highlights

- Install a native CLI on macOS or glibc-based Linux.
- Author and validate `.tap.yml` workspaces.
- Run the local MySQL-to-MongoDB Quickstart with an initial snapshot and CDC.
- Register the published MySQL and MongoDB connector JARs, apply resources, and
  operate a pipeline from the interactive CLI.

## Release components

The published Quickstart uses the pinned
`ghcr.io/tapstate/tapstate:0.1.0` server image and the separate
[MySQL and MongoDB connector preview assets](https://github.com/tapstate/tapstate/releases/tag/connectors-preview).
The connector bundle supports that Quickstart; it is not a support matrix for
every connector guide.

## Known limitations

- The Quickstart is the only verified end-to-end path: a local MySQL source,
  MongoDB target, initial snapshot, and CDC. Connector guides and catalog
  metadata do not establish that every connector combination was exercised in
  `v0.1.0`.
- The server is single-node and keeps runtime state in memory.
- A server restart replays from the source instead of resuming from a durable offset.
- Stateful Nest and Join transforms are declared but refused by the current runtime.
- Queryable and push-based serving are not part of the verified release path.
- Delivery guarantees, ordering, schema evolution, and type conversion outside
  the published path need environment-specific verification.
- `run`, `export`, `diff`, and `edit` are listed by the CLI but are not implemented.
- The Quickstart can return success when its observed target count is below five;
  confirm that it prints `the target now holds 5 rows`.

Use non-production systems and data for evaluation. See
[Install tapstate](/docs/overview/install) for supported platforms and system
requirements.
